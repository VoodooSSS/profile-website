# Profile Website

HTML과 CSS로 만든 개인 프로필 웹사이트입니다. 프레임워크는 쓰지 않았습니다.

## 로컬에서 실행

```bash
npm start
```

브라우저에서 http://localhost:3000 을 엽니다. 서버(`server.js`)는 Node.js 내장 `http` 모듈만 사용합니다.

## 배포

`main` 브랜치에 push하면 두 곳 모두 자동으로 갱신됩니다.

- Vercel: https://profile-website-umber-mu.vercel.app
- GitHub Pages: https://voodoosss.github.io/profile-website/
